# bellarulox.com

Sitio web de Bellarulox / Marian Montilla, listo para publicar con GitHub Pages.

## Paginas

- `index.html` - inicio, con las tres puertas de entrada (Arquitectura de Sistemas, Del Caos al Foco, Recursos) y la calculadora con puerta de entrada por email
- `sistemas.html` - Arquitectura de Sistemas para tu Negocio (consultoria B2B)
- `del-caos-al-foco.html` - Del Caos al Foco (membresia personal)
- `recursos.html` - catalogo de recursos individuales de bajo costo

## Antes de publicar

1. Reemplaza el correo de contacto: busca marianm@bellarulox.com y confirma que sea el que quieres mostrar publicamente.
2. Verifica los enlaces de redes sociales en el footer de cada pagina (Instagram, TikTok, Threads, YouTube, LinkedIn).
3. Conecta el formulario de la calculadora a Kit (ConvertKit) cuando tengas tu cuenta lista.

## Como publicar (GitHub Pages)

1. Sube estos archivos a este repositorio (rama main)
2. Ve a Settings -> Pages, selecciona la rama main como fuente
3. En Custom domain escribe bellarulox.com
4. En tu proveedor de DNS (SiteGround), agrega los registros A y CNAME que apuntan a GitHub Pages
